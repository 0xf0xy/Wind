## > Overview

**Wind** is a pattern-driven wordlist generation engine designed to model real-world password construction behavior.

It produces high-probability credential candidates by combining user-defined patterns, common substitutions, and structured permutations.

Built to support dictionary-based attacks, controlled brute-force strategies, and targeted credential research by reflecting how users actually create passwords.

<br>

## > Install

```bash
git clone https://github.com/0xf0xy/Wind.git
cd Wind
sudo pip install .
wind -h
```
